SCIENCE FAIR PROJECT SITE

Requirements:
- Node.js installed

Steps:
1. Open this folder in VS Code.
2. Open Terminal in this folder.
3. Run: node server.js
4. Open: http://localhost:3000
5. JSON API: http://localhost:3000/api/projects

The site uses a native Node.js HTTP server, serves HTML/CSS/JavaScript,
provides a JSON API, logs requests, and returns a 404 response for unknown routes.
